# AI Prompt History

## Overview

AI assistance was used during the development of this assignment for understanding requirements, generating and refining code, debugging issues, and improving the visual similarity between the generated web pages and the reference PDFs.

The following summarizes the main prompts and areas where AI assistance was used.

---

## 1. Project Setup

**Prompt:**

> Tell me step by step to start VS Code for the PDF generation assignment.

**Purpose:**

Used to set up the project structure and create the required files.

---

## 3. PDF Recreation

**Prompt:**
